# Food Delivery Platform

A full-stack food delivery platform built using Django, Django REST Framework, PostgreSQL, and JavaScript.

## Tech Stack

- Python
- Django
- Django REST Framework
- PostgreSQL
- JWT Authentication
- JavaScript
- Bootstrap
- Pytest
- Swagger / OpenAPI


## Run locally

   python manage.py migrate
   python manage.py runserver

   Open <http://127.0.0.1:8000/> in your browser. Django's development server
   runs locally on port 8000 by default.
